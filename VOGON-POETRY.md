# Vogon Poetry Generator

Part of AgentPipe issue #1928 - Vogon Poetry

## Overview

A Python module that generates poetry in the style of Vogons from Hitchhiker's Guide to the Galaxy. The third worst poetry in the universe (after the Azgoths of Kria and the Dentrassi).

## Features

- **Original Poem**: The complete Vogon poem from the issue
- **Random Generation**: Generate new Vogon poetry using randomly selected unpleasant words
- **Maximum Unpleasantness**: Designed to cause significant brain damage

## Usage

```python
from vogon_poetry import VogonPoetry

poet = VogonPoetry()

# Recite the original poem
print(poet.recite())

# Generate a random poem
print(poet.generate_poem(6))
```
